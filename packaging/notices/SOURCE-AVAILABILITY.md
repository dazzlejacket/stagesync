## Where the corresponding source comes from

The corresponding source is the published source of the exact versions above, as distributed on crates.io. Nothing is patched, vendored or re-generated: StageSync depends on the unmodified crates.io release of each crate.

For each crate, the source archive is:

```
https://crates.io/api/v1/crates/<crate>/<version>/download
```

which redirects to `https://static.crates.io/crates/<crate>/<crate>-<version>.crate`. The SHA-256 of that file is the checksum recorded in `Cargo.lock` in the table above, so a download can be verified against the lock file without trusting anything else:

```
curl -fsSL -o symphonia-0.6.1.crate \
  https://crates.io/api/v1/crates/symphonia/0.6.1/download
sha256sum symphonia-0.6.1.crate
```

The whole set can also be materialised from the crates.io index without any of the above, which is the route a distributor should prefer because it is driven by the lock file itself:

```
cargo vendor --locked --versioned-dirs vendor/
```

That command writes the source of every pinned dependency into `vendor/`, including the thirteen crates above, and the checksums it verifies against are the ones in `Cargo.lock`.
